# 欢迎使用 Antumi

Antumi 在一个窗口里驱动你装好的 Claude Code、Codex、Cursor、OpenCode、Pi 和 DeepSeek Harness。聊天、改代码和批准操作，和各家自己的桌面端差不多。先做完下面的准备，会话才能发出去；后面的用法用到再看。

## 第一步：安装并登录一个 Agent

**必要。** 至少装好一个 Agent，它才会出现在新建会话里。

1. 打开 **设置 → 本机 Agent**。
2. 在 **已安装** 里确认它在，开关是开的。关掉的不会出现在新建会话里。
3. Claude Code、Codex、Cursor 还要显示 **已登录**。显示 **未登录** 时，按那一行的登录命令在终端里登录，再点 **重新检测**。
4. 列在 **可安装** 里，或只装了 Cursor 应用、还没有 CLI：点 **在终端安装**，或复制旁边的安装命令自己跑。装完点 **重新检测**。

OpenCode、Pi、DeepSeek Harness 不显示登录状态，也没有自己的订阅账号。装好之后还要做第二步，或按那一行的说明在它们自己的终端里配好模型，才能回答。Claude、Codex 不登录自己的账号、改走服务商时，也是做完第二步再开聊。Cursor 只能用自己的账号。

准备好之后，点这篇指导上方的 **开始第一条会话**，选一个 Agent，写下第一条消息。

## 第二步：设置服务商

**用 Claude、Codex 或 Cursor 自己的账号时可以跳过。** 要用火山方舟、智谱 GLM、Kimi、MiniMax、阿里云百炼这类编程套餐，或让 OpenCode、Pi、DeepSeek Harness 回答，就在这里配。

1. 打开 **设置 → 服务商**，点 **添加服务商**。
2. 选一个套餐。标着 **未验证** 的是按各家文档填好的，还没在 Antumi 里用真 Key 测过。选 **自定义** 则自己填地址和模型。
3. 填名称，粘贴 API Key。点 **去控制台获取** 打开这家的控制台。Key 只存在本机，不进 Agent 的配置。
4. 模型一行一个，预设已经填好。确认 **默认模型**，以及标题、翻译、提交说明用的 **小模型**。
5. 勾选 **给哪些 Agent 用**。Cursor 用不了服务商，只能用自己的账号。
6. 点 **保存并测试**。每一项前面是 ✓ 就可以用。失败时看服务商返回的原话，多半是 Key、地址或模型名不对。

新建会话或任务时，输入框里的 **服务商** 选这个套餐。不选就用 Agent 自己登录的账号，用量算官方额度；选了就按服务商计费，不占官方额度。会话一旦开始，服务商就不能换。

## 第三步：配置多个账号

**可选。** 只有 Claude Code 和 Codex 能登多个账号。一个账号够用就跳过。

1. 打开 **设置 → 账号**。
2. 点 **添加 Claude Code 账号** 或 **添加 Codex 账号**。名称可以空着，也可以写成「工作」。
3. 点 **添加并登录**，在下方终端里按提示完成。结束后这里会显示邮箱。
4. 点 **设为当前**。之后新开的会话用它；正在跑的会话保持原来的账号。列表里的 **本机账号** 就是你原来登录的那个，删不掉。
5. **额度用完时自动换下一个账号** 默认开着：撞上限的会话会立刻换到还有额度的账号接着跑。想自己切，就关掉它，然后在底部状态栏悬停用量，在卡片里点另一个账号，或点 **管理账号…**。

换号后会话历史还在，同一个会话可以接着聊。

## 第四步：安装任务或 Bug 来源

**可选。** 要把 GitHub、Jira、Linear 或禅道里的任务、Bug、需求带进 Antumi，先安装对应来源插件。手写任务和普通聊天可以直接使用。

1. 打开 **设置 → 插件 → 推荐插件**，找到要连接的平台，点 **安装插件**。Antumi 在这时从该插件独立的 GitHub Release 下载 ZIP，安装包里不预装这些来源。
2. 安装成功后，打开 **设置 → 集成 → 对应来源名称**。先填站点和筛选条件，再点 **保存设置**。
3. 点 **登录**，按提示填写该平台的 API Key 或 Token；Jira 还需要登录邮箱。确认 **同步到收件箱** 开着。
4. 回到侧栏的 **收件箱**，点 **立即同步**。之后会定期同步符合筛选条件的事项。
5. 找到一条事项，点 **导入任务**，再给新任务选项目和 Agent；也可以先点 **会话排查**，在会话里了解问题。

| 来源 | 主要设置 |
|---|---|
| GitHub | Personal access token 和搜索条件。只看 Bug 时，可在原条件里加 `is:issue label:bug`，标签名按仓库实际填写 |
| Jira | Jira 站点、登录邮箱、API token 和 JQL；在 JQL 中按你们的事项类型筛选 Bug |
| Linear | 个人 API Key，以及团队、项目、指派人和状态筛选 |
| 禅道 | 完整 RESTful API v1 地址，例如 `https://zentao.company.com/zentao/api.php/v1`，再填 Token、事项类型和执行 / 产品 ID；只看 Bug 时选择 **Bug** 并填写产品 ID |

禅道支持企业自建域名、端口和部署子目录；内网站点需要这台电脑能够访问。地址更改后需要重新登录。

推荐里没有的来源，也可以在 **从其他位置安装** 中选 **GitHub Release** 并填 `owner/repository`，或选择开发者提供的本地 ZIP。第三方插件在确认信任后安装；开发者需要发布带插件 ZIP 的 Release，只有源码或尚未发布安装包的仓库还不能下载安装。

安装完仍没有事项时，先检查登录和 **同步到收件箱**，再看筛选是否过窄、账号是否有目标项目权限。插件可以在 **设置 → 插件** 检查更新、停用或卸载；来源配置、凭据和已经导入的任务会保留。

想开发自己的来源插件，可以阅读 [插件开发指南](https://github.com/flyhero/antumi/blob/main/docs/PLUGINS.md)。

## 用起来

下面都不是开始前要配的。

### 多个 Agent，额度一眼看清

![新建会话时选择 Agent，Cursor 标着推荐](assets/guide/agents.png)

新建会话时直接挑 Agent。标 **推荐** 的是眼下最该用的那个：额度最宽裕，或者额度快重置了、不用就浪费。

![底部状态栏里各个 Agent 的用量](assets/guide/usage.png)

底部状态栏常驻每个 Agent 的用量。悬停可以看恢复时间，重置卡也在这里用。登了多个账号时，卡片里可以切换。

### 无缝移交

![输入框左下角的 Agent 菜单](assets/guide/handoff.png)

额度用完了，或者想换个 Agent 接着做：点输入框左下角的 Agent 名称，换一个，写句补充说明，点 **移交**。新 Agent 会带着聊天记录，在同一个目录里接着做。

### 预约：额度恢复后或到点再发

![点时钟按钮后弹出的「预约发送」](assets/guide/schedule.png)

1. 在输入框里写好消息。
2. 点输入框右下角的 **时钟** 按钮。
3. 选 **额度恢复后**，或 **指定时间**。
4. 点 **预约**。

| 还能预约 | 在哪里 |
|---|---|
| 任务 | 任务工具栏上的时钟按钮 |
| 计划批准 | 计划卡片上的 **预约批准** |
| 查看、改时间、取消 | 状态栏的「N 个预约」，或总览的「接下来」 |

到点后，Agent 按弹窗里写的模式无人值守运行，点 **在设置里改** 可以换。电脑睡着时预约不会运行，可以打开状态栏咖啡图标的「保持电脑唤醒」。

### 总览：所有等你的事

![总览的指标和「需要我」列表](assets/guide/overview.png)

侧栏最上方的 **总览** 汇总所有会话和任务：等你批准或回答的、待办、在跑的、接下来要做的、未读的。批准可以直接在这里点。

### 研发小队

![小队里队长、开发、评审的配置](assets/guide/squad.png)

给队长、开发、评审分别配 Agent、模型和职责，再把任务交给整支小队。队长先和你确认计划，再派活：开发串行进行，只读分析可以并行。

### 分屏：两个会话并排

![会话右键菜单里的「在右侧分屏打开」](assets/guide/split.png)

| 操作 | 方法 |
|---|---|
| 打开分屏 | 右键另一个会话 → **在右侧分屏打开**；或按住 ⌘ 点它；或把它拖到聊天区 |
| 切换焦点 | ⌘1 左侧，⌘2 右侧 |
| 调整宽度 | 拖动中间的分隔线 |
| 收起 / 恢复 | ⌘\ |

两侧可以分别输入、看进度、处理批准。

### 小助手与翻译

![选中文字后的右键菜单](assets/guide/helper.png)

选中回复里的一段，右键：

- **交给小助手**：在右侧打开，用轻量模型和独立上下文解释、追问，不占主会话。
- **翻译**：只翻译选中的这段。回复不是你的语言时，回复下方也会出现 **翻译** 按钮，可以翻整条。

![设置里的「翻译」](assets/guide/translate.png)

| 设置项 | 位置 |
|---|---|
| 翻译成哪种语言、是否自动翻译 | **设置 → 翻译** |
| 翻译用的模型 | **设置 → 本机 Agent →「轻量任务用的模型」** |

### 还有这些

| 功能 | 怎么用 |
|---|---|
| 待办 | Agent 记下要你之后做的事，在检查器的 **待办** 页签里勾掉 |
| 会话分组 | 侧栏 **会话** 的「分组和排序」，按项目、Agent 或运行状态分组 |
| 关窗不停 | Agent 在后台进程里运行，关掉窗口也不打断 |

随时可以在 **设置 → 关于** 里再打开这篇指导。
